# chatglm-brain

把**智谱清言网页版**（chatglm.cn，智谱）当作编码 agent 的**外部大脑**：它出推理与内容，你的 agent 出执行。
本地确定性 CLI（`cgb`）驱动官方网页，不需要 API key，不做逆向代理。

- 状态：**第六个大脑，真机测试进行中**（对话流 / 附件 / 生图 / 生视频额度均已实测，见下）
- 给 agent 的完整说明书是 [SKILL.md](SKILL.md)（选择器、失败分类、协作协议都在那里）

## 风控触发频率（真机实录，2026-09-12）

> 结论先行：**触发点是「对话流发送消息」**；导航与浏览类操作（doctor / list-models /
> 打开画图、视频工作流页）全程零触发。低频使用（间隔 ≥10 分钟一次发送）基本不会遇到验证。

### 对话流实测（游客态，同一 profile，n=8 发）

| 发送序号（按静置后计） | 距上次发送 | 结果 |
| --- | --- | --- |
| 第 1 发 | 静置 ≥10 分钟 | ✅ 通过（2 组样本均如此） |
| 第 2 发 | 4–9 分钟 | ✅ 通过 |
| 第 3 发起 | 4–5 分钟 | ❌ 连续 3 发全部触发（100%） |

- 进入风控态后：**每个新会话都弹**（页面加载即带验证），且**真人拖动也大概率失败**
  （「验证失败，请刷新」死循环——行为风控已把该环境指纹拉黑，与拖动者无关）；
- **持续重试只会延长风控时间**（实测与社区调研一致）；此时唯一正确动作是停止发送、等待冷却；
- 冷却观察：进入风控态后停发约 40 分钟（期间只浏览不发送），再次发送**仍触发**——
  冷却时长 >40 分钟，精确值未测（样本 1）。

### 工作流页与登录态

- **AI 画图 / AI 生视频工作流页**：连发 6 次生成零触发（另有各自的门槛：
  游客生图 5 轮/天后弹登录墙、游客生视频直接要短信验证）；
- **登录态**：工作流页 10 次会话（3 次生图 + 1 次生视频 + 浏览）零触发；
  对话流登录态样本不足，未下结论（粗略印象是触发率显著更低）。

### 风控恢复策略（项目规则，详见 SKILL.md）

1. **绝不清登录态 / profile 来"修复"风控**（清 profile 连登录带指纹一起没）；
2. 触发风控 → CLI 自动**关闭浏览器再重开**（登录态保留，重开最多一次），重开后沿用原登录态；
3. 重开后仍弹验证 → 停手等冷却，不重试；人机验证一律由**用户本人**操作，CLI 绝不代拖。

## 额度实测摘要

| 能力 | 游客 | 登录态 |
| --- | --- | --- |
| 对话问答 | 可用（有风控频率限制，见上） | 可用 |
| AI 画图（快速模式） | **5 轮 / 20 张 / 天**，第 6 轮弹登录墙；1024×1024 JPEG，单轮 15–23 秒 | **免费**（不扣积分，整页刷新对照实测） |
| AI 生视频（清影 5s） | 不可用（进页即弹短信验证） | **50 积分/条**（10s 档 150 积分；1280×720，实测 5.2s / 1.5–4.3 MB） |

- 积分余额显示在侧栏用户名下方；**SPA 内导航不刷新，读余额必须整页 reload**；
- 价格标注在「生成时长」菜单里；发送按钮上的「XX积分」文字是当前余额，不是单价。

## 命令面

```bash
node scripts/cgb/cli.mjs doctor [--deep] --json   # 体检（--deep 真机探测）
node scripts/cgb/cli.mjs ask --prompt "..." --thread new --json
node scripts/cgb/cli.mjs ask --prompt "..." --attach a.png --json   # 附件（图片/文档）
node scripts/cgb/cli.mjs list-models --json       # v1 只读当前模型（GLM-Flash极致）
node scripts/cgb/cli.mjs login / logout / setup / logs / thread / session
```

全局选项：`--json` / `--debug` / `--timeout <ms>` / `--captcha-wait <ms>` / `--keep-open`。

## 状态与隐私

状态目录 `%LOCALAPPDATA%\chatglm-brain\`（`CGB_STATE_DIR` 可覆盖）：
`profile/`（登录态 + 设备指纹，**勿同步分享**）、`storage-state.json`、`downloads/`、
`threads/`、`outputs/`（审计元数据）、`logs/`、`debug/`（排障快照，含未脱敏正文，排障后删除）。
