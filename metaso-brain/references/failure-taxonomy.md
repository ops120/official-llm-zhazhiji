# 失败分类与恢复动作

`msb` 的所有失败都是可枚举的：`{ok:false, reason, message?, retryAfterMs?}`。
按下表处理；需要用户介入时**一次只给一个动作**。

| reason | 含义 | 动作 | 对用户说 |
| --- | --- | --- | --- |
| `HUMAN_VERIFICATION_REQUIRED` | 人机验证未在时限内完成（CLI 等待期间已提醒并暂停超时时钟；**绝不代操作**） | 停；让用户在浏览器完成验证后重试；或加大 `--captcha-wait` | 「metaso 触发了人机验证，需要你本人在浏览器里完成；我这边只能等，不能代操作。」 |
| `LOGIN_REQUIRED` | 出现登录墙（**游客点深度研究必弹**：文案「登录后继续搜索」），或风控重开后发现原登录态丢失 | 让用户跑 `msb login` 后重试 | 「深度研究需要登录秘塔账号，请登录后我再继续。」 |
| `RATE_LIMITED` | 限流 / 频率提示（站点用瞬时 toast，失败返回会带命中的**页面文案**） | 停，按 `retryAfterMs` 退避；深度研究疑似有频控（同题连发 30 秒内触发过一次），失败文案会写明原因 | 「请求太频繁或额度受限，等一会再试。」 |
| `COMPOSER_NOT_FOUND` | 输入框定位失败 | `doctor --deep`；多半是改版 → 按 `SITE_CHANGED` | 不要把 DOM 细节讲给用户 |
| `SITE_CHANGED` | 选择器漂移（如首页档位控件 / textarea 锚点丢失） | **版本问题**：`doctor --deep` 定位；告知维护者修 `scripts/msb/src/site.mjs` 并发版。不要现场硬试 DOM | 「metaso 页面改版了，需要更新 metaso-brain。」 |
| `SEND_FAILED` | 注入 / 发送 / 档位切换未生效 | 重试一次；仍失败按 `SITE_CHANGED` | — |
| `STREAM_STALLED` | 流式停滞 / 超时 | 已捕获内容标注「可能截断」；**深度研究实测 >10 分钟**，9 分钟级超时不够 → `--timeout 1500000` 重跑（CLI 失败消息已带此提示） | 「回答可能不完整。」 |
| `THREAD_LOST` | 会话 URL 失效（CLI 会自动回落主页开新搜索并在返回里标 `threadLost:true`） | 正常现象；需要延续上下文时重新贴关键背景 | — |
| `INVALID_ARGUMENTS` | 参数错误：`--model`（不存在）、未知 `--intensity`、复用线程时切档、`--attach`（v1 未支持） | 按提示改参数；复用线程要切档请加 `--thread new` | — |
| `LOCKED` | 另一个 msb 会话持有全局锁（profile 是浏览器排他资源，同一时间只允许一个会话） | 等持锁会话结束（失败信息带 pid 与命令）；陈旧锁（持有进程已死）会自动接管，无需处理 | 「有另一个任务正在使用秘塔浏览器（pid=…），等它跑完我再试。」 |
| `BROWSER_CLOSED` | 浏览器窗口被用户关闭 | 重跑同一条命令即可 | — |
| `DEPENDENCY_MISSING` | 依赖缺失 | 自愈：`setup`（或见 install.md） | — |
| `SENSITIVE_BLOCKED` | 闸门拦截（私钥块无条件拒绝） | 移除敏感内容或改用摘要；确需发送必须用户明确同意 | 「内容里含敏感信息，已被拦截；需要你确认才能发送。」 |
| `PAYLOAD_TOO_LARGE` | 正文超过 50 KB | 先摘要或分片；确需整段加 `--allow-large` | 「内容太长，我先压缩一下再发。」 |
| `INTERNAL_ERROR` | 未归类异常 | 带 message 上报维护者 | — |

## 硬规则

- **绝不**把失败伪装成结果；**绝不**静默降级后不告知
  （档位没切换成功必须如实报 `modes.intensity` 与请求值的差异）。
- **绝不**为绕过失败去手工操作 DOM——机制只存在于 CLI。
- **绝不**尝试自动完成人机验证——那是风控红线，必须用户本人完成。
- 重试有上限：同类失败最多 2 次，之后交用户或上报维护者。
- 深度研究模式耗时数分钟是**正常**的，不要因为慢就判失败。
