## 1. deepseek-brain → chat.deepseek.com（dsb）

**定位**：深度推理与代码主力；机队里唯一「完全免费、无付费档位」的大脑。

**模型**：调研称当前为 V4 Pro（默认），1M token 上下文，Non-Think / Think High / Think Max 三档推理模式。
（⚠️ 与 README「网页版只有『深度思考』『智能搜索』两个开关」不一致，疑似站点近期改版，以页面实际为准。）

**特长**

- **代码与深度推理**：LiveCodeBench Pass@1-COT 93.5%、HumanEval 76.8%，公开榜单第一；SWE-Bench 领先，每任务成本约为竞品三分之一；SuperCLUE 智能体编程子项 77.19，国内模型领先。
- **长上下文处理**：1M token 窗口 + 文件上传，适合大段代码库分析与超长文档。
- **免费且无广告**：网页版完全免费，无订阅、无 Plus、无广告，联网搜索与文件上传均含在内。

**短板**：风控较强（能识别数据中心 IP；微信登录不支持海外 IP、Google 登录不支持大陆 IP，频繁换设备可能触发封禁）；无生图/生视频/音乐；文件分析以文本提取（OCR）为主，不具备原生视觉感知。

**免费额度**

| 维度 | 免费版情况 |
| --- | --- |
| 每日对话次数 | 官方未公布固定配额；第三方实测约 150~200 次/24h（含思考链），按 UTC+8 自然日重置，高峰期可能「服务器繁忙」而非硬性拒绝 |
| 深度思考 | 免费可用（Think High / Think Max 均无需付费），计入总额度 |
| 深度研究 | 无独立 Deep Research 产品，联网搜索 + 深度思考组合替代 |
| 生图/生视频/音乐 | ❌ 不支持 |
| 文件上传 | 单文件 ≤ 100MB，一次最多 50 个；PDF/DOCX/XLSX/TXT/JPG/PNG（仅 OCR 识别文字） |
| 上下文窗口 | 1M token |
| 联网搜索 | 免费，计入总额度 |
| 付费档位 | 无（免费是唯一方案） |

可靠度：中。「150~200 次/天」来自第三方实测，官方从未公布配额数字。

## 2. doubao-brain → doubao.com（dbb）

**定位**：全模态产出最全——图/视频/PPT/表格/深入研究/录音纪要；中文办公场景首选。

**模型**：豆包 2.1 系列（Turbo / Pro），智能体架构。

**特长**

- **全模态产出**：图片生成、视频生成（Seedance 2.0/2.5）、AI PPT、AI 表格、深入研究、语音与视频通话、录音纪要；免费版即有视频生成能力。
- **办公任务模式**：可做多步操作（项目规划、文件处理、工具调用），实测能完成行业调研报告、课件 PPT 等复合指令。
- **本地生态**：月活 3.45 亿，中文语境理解好。

**短板**：数据图表识别需人工兜底；代码能力与 DeepSeek 有差距；免费版高峰期可能降速。

## 3. gemini-brain → gemini.google.com（gmb）

**定位**：Deep Research 深度研究 + Google 生态整合（Gmail/Drive/Photos/YouTube）+ 高清生图与 Canvas。

**模型**：免费版默认 Flash 变体；Pro 有使用限制。

**特长**

- **Deep Research**：免费版可用，是免费层级少有的完整 agentic 研究工作流。
- **Google 生态整合**：跨应用工作流能力强，可从历史聊天学习。
- **多模态理解**：原生接收音频/视频输入；Nano Banana 系列生图。
- **Notebooks**：2026 年 4 月起对所有用户免费开放。

**短板**：地区限制最严格（注册地 + IP 双重验证）；免费版上下文仅 32K；中文与国内信息覆盖不如国内模型。

**免费额度**

| 维度 | 免费版情况 |
| --- | --- |
| 每日对话次数 | 2026-05-17 起改为**基于运算量的弹性额度**：每 5 小时刷新 + 每周总上限，提问越复杂消耗越多；旧制约 30 次/天（Pro 模型） |
| 深度思考（Pro / Deep Think） | 免费可用（美国用户），但消耗大量运算量 |
| Deep Research | 免费可用；旧制约 3 次/天，新运算量制下每次消耗极大 |
| 生图 | Nano Banana 2 免费可用，旧制约 20 张/天，新制计入运算量池 |
| 生视频/音乐 | 免费可用，消耗大量运算量 |

| 付费档位 | AI Plus $7.99/月（128K、2 倍额度）；AI Pro $19.99/月（1M、4 倍）；AI Ultra 更高 |

可靠度：额度机制部分高；运算量制具体扣减规则 Google 未完全公开，实际可用次数因复杂度浮动。

## 4. grok-brain → grok.com（grb）

**定位**：X 平台实时信息与舆情监测——机队里不可替代的独有优势。

**模型**：Grok 4.3（2026 年 5 月起旗舰），1M token 上下文，支持原生视频输入。

**特长**

- **X 平台实时数据**：原生接入 X 信息流，可搜帖、读时间线、看 @ 提及、汇总平台动态；2026 年 8 月的 Grok Bot 进一步强化。
- **实时新闻理解**：借助 X 数据解释全球事件。
- **幻觉率低**：4.1 版本幻觉率 4.22%，EQ-Bench v3 得分 1586。
- **风格大胆**：过滤较少。

**短板**：中文与本土信息覆盖弱；X 在部分地区受限；敏感话题偶有信息验证不力。

**免费额度**

| 维度 | 免费版情况 |
| --- | --- |
| 每日对话次数 | xAI 已弃用固定配额制（不再公布数字）；第三方实测约 10 次/天（UTC 午夜重置），弹性调整，高峰期软上限更低 |
| DeepSearch（深度搜索） | ❌ 付费专属 |
| 生图 | ❌ 免费版已停用（Grok Imagine 免费额度于 2026-03-19 取消，触发付费墙） |
| 生视频 / 音乐 | ❌ / ❌ |
| 文件/图片上传 | ❌ 免费版不支持图片上传 |
| 上下文窗口 | 免费版有限制（付费版 128K~256K），具体值未公开 |
| 联网搜索 | 基础搜索免费；DeepSearch 付费 |
| 语音 | 免费版 iOS 5 分钟/天，桌面端 30 分钟/天 |
| 付费档位 | X Premium $8/月（约 50 次/天）、X Premium+ $16/月（约 200 次/天）、SuperGrok $30/月（无限制 + DeepSearch + 生图） |

可靠度：中低。固定配额制已被弃用，所有数字均为第三方观察，xAI 保留随时调整权利。

## 5. qwen-brain → qianwen.com（qwb）

**定位**：中文与本土信息 + 思考研究模式；**机队里唯一匿名可用（游客模式）**的大脑。

**模型**：Qwen3.7-Max / Qwen3.8-Max 系列，百万级上下文（APP 端），原生全模态。

**特长**

- **视觉到代码端到端**：从图像/设计稿/视频生成 SVG、网页与交互式前端——调研认为这是机队中独有的「视觉→代码」链路（⚠️ README 把「可运行代码/页面/动画（Canvas）」列为 gemini 独有，两者可能互补：千问偏视觉→代码、Gemini 偏 Canvas 交付）。
- **永久免费**：个人用户全核心功能免费、无次数限制、无广告（Qwen3.8-Max 也在免费范围）。
- **中文 + 本土信息**：阿里生态（淘宝/支付宝/高德）场景理解深入。
- **办公创作链路**：文案、PPT、代码调试、长文档解析一条龙。

**短板**：代码基准不及 DeepSeek；无独立视频/音乐生成（有生图）；智能体自主执行仍在迭代。

**免费额度**（注意：**APP 端与网页端待遇不同**，本项目驱动的是网页端）

| 维度 | 免费版情况 |
| --- | --- |
| 每日对话次数 | 不限次（高峰期可能限流） |
| 思考研究 | 免费可用，无独立次数限制 |
| 生图 | 免费可用，Qwen-Image-Edit 无限制 |
| 生视频 | 每日 10 次免费（Wan-2.5 / HappyHorse，自然日 + 设备指纹重置）；5/10 秒免费、15 秒付费；超量 26 元/10 额度起 |
| 文件上传（APP 端） | 万页级 PDF/DOCX/TXT，单次最高 1000 万中文字符（约 1500 页），免费 |
| 文件上传（网页端） | 按页计费（基础解析 0.1 元/页），上下文常被截断至 32K |
| 上下文窗口 | APP 端超长；**网页端免费版实际约 32K** |
| 联网搜索 | 免费 |
| 付费档位 | 无独立 C 端包月会员；2026 年 8 月起有办公助理付费版（三档），视频额度单独按份购买 |

可靠度：中高。「对话不限次」与「视频 10 次/天」多来源一致；网页端 32K 与 APP 端差异以实际入口为准。

## 6. chatglm-brain → chatglm.cn（智谱清言，占位未接入）

**定位建议**：中文长文档精读 + 公文/专业写作的**垂直补充**，不做通用主力。

**模型**：GLM-5 / GLM-5.2（7450 亿 MoE、激活 44B，1M 上下文，MIT 开源）。

**特长**

- **中文长文档分析**：自研语义锚点记忆网络，针对百页白皮书、整套招标文件、法律合同的信息衰减做了优化；术语校准表现好。
- **公文与专业写作**：格式规范、政策引用准确，适合公文/财报/合同初稿。
- **开源生态**：MIT 协议，可本地化部署；chat.z.ai 提供海外入口。

**短板**：多模态产出薄弱（无视频/音乐，生图不突出）；实时信息一般；用户基数小（2500 万）；网页端默认非 GLM-5，需手动切换。

## chatglm.cn 是否值得作为第六个大脑接入？

**结论：值得接入，定位为「专业中文长文 + 公文写作」的垂直补充，而非通用主力。**

- 语义锚点技术与机队互补：DeepSeek 的 1M 上下文是「容量大」，GLM-5 是「读得准」。
- 公文/法律/财报场景的格式规范性与术语准确性，其他站点难以覆盖。
- MIT 开源意味着未来可本地化部署，降低对网页版的依赖。
- 风控与地区限制最宽松，网页自动化维护成本低。
- 注意：网页端需手动切换到 GLM-5，多模态产出几乎空白、实时信息弱；若机队核心需求是代码 + 多模态 + 实时信息，其边际价值有限。
